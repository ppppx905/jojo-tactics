> 这份文档**覆盖** `第八章设计草案.md` 里"单场战斗/三人同场"的部分；数值与两条机制的出处仍看那份。
> 现状：第①②③④步已做完（两个 boss 的数据与素材、反光点＋吊死者跳跃、场边冷枪＋弹道预告）。

## 一、为什么改
用户原话：**「剧情上来说是阿布德尔为了救和皇帝单挑的波波死的，所以把这关改为波波和皇帝单挑」**
→ 最终定成**两个阶段**：「先是波波 vs 皇帝，再是波波和花京院 vs 吊死者」。

## 二、两阶段结构（用户拍板）

### 阶段 1：波鲁纳雷夫 单挑 霍尔·霍斯（皇帝）
- **玩家**：`polnareff`（真人）。**阿布德尔不上场**。
- **敌方**：`emperor`（单单位：皇帝不单独占棋子）。
- **胜负（用户定）**：**把皇帝打到半血以下**就触发演出——
  他开那一枪 → 旁白：**阿布德尔扑上来替波波挡下、倒下了** → **皇帝趁乱撤退** → 阶段 1 结束。
  （不用另做"替死"机制：演出交给剧情文本＋一条横幅即可；**不是**"打倒全队"那套口径。）
  ⚠️ 触发那一击**把他的血夹到 1**（血条别显示成负数）。
- **皇帝在阶段 1 必须能被打伤**：撤掉"打不死（`immune`）/ 钉在外圈（`pinned`）"两条
  （那是"他只是外围骚扰"的旧设计；单挑要能追能打）。
  他仍然**射程 4**、**攻击 7**、**移动 2**，靠放冷枪与拉开距离打——冷枪就是他这一战的全部内容。
- **冷枪（阶段 1 的核心）**：每 **2** 回合一次；**开火前一回合在地面画出弹道与目标格**；
  **净伤 6 点真实伤害（无视一切防御）**；目标格上没人＝打空（就记一条日志）。

### 阶段 2：波鲁纳雷夫 ＋ 花京院（电脑） 对 吊死者
- **玩家**：`polnareff`（真人）＋ **`kakyoin` 由电脑控制**（`ally`）。
- **敌方**：`geil`（J·凯尔 & 吊死者，本体 + 替身两枚、共享血 45）。
- **胜负**：**打倒 J·凯尔**（沿用现在的 `keySlot` 口径）。
- **反光点**（第③步那套）在这一阶段生效：吊死者只在反光点之间跳；火焰能封镜。

## 三、引擎要加的东西（本次最大的一块）
1. **一章多场战斗**：`scenes` 里允许出现 **两个 `{ kind:'battle' }`**，各自带**自己的阵容**；
   现在的 `storyBattleScene()` 假设"一章只有一场" ✗，要改成能算出**下一场还没打完的**那一场；
   章节**完成**＝最后一场之后的正文也读完。
2. **每场战斗各自的阵容**：新增按幕声明的席位（例如
   `{ kind:'battle', lineup: { player:'polnareff', enemy:'emperor' } }` /
   `{ kind:'battle', lineup: { player:'polnareff', ally:'kakyoin', enemy:'geil' } }`），
   开打时照它登记（`setRoster({...,story:true})` 那套继续用）。**战斗之间状态互不影响**（每场都是新对局）。
3. **"打到半血即胜"的剧情机制**：像 `TEMPERANCE.unmaskAt` 那样做成章节数据
   （例如 `phaseWin: { slot:'p2', hpRatio:0.5, banner:..., text:... }`），
   在既有伤害结算之后判一次；触发时**结束这一场**（判玩家胜）并按剧本往下走。
4. 反光点、冷枪的代码**都保留**，只是**分属两场**：冷枪在阶段 1 生效、反光点在阶段 2 生效
   （用各幕的旗标声明，别写成"只要在第八章就都生效"）。
