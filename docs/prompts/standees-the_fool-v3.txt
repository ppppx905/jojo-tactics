Use case: stylized-concept
Asset type: JOJO 第三部战棋替身「愚者」的独立全身棋子原画（第三版：按官方替身卡片的造型重画），后续去底缩放成 192×288 透明立绘。
Primary request: 只画一个替身、居中、全身：**愚者（The Fool, ザ・フール）**——伊奇的替身。严格按官方造型：**灰银金属质感的四足骷髅战兽 + 头顶红橙色羽毛战冠 + 红蓝垂绳**。画面里只有这一个形体。
Subject:
- **头部**：一整块**灰白色的骷髅式面具**，脸向前拉长成**长吻／长喙**；吻部两侧**露出成排的白色牙齿**（像骷髅咧嘴）；两个眼窝是**深陷的黑色空洞**（不要发光的红眼）；颅骨后侧有棱线。
- **头顶的羽毛战冠（最关键、绝对不能少）**：从颅骨后方向上、向外呈**扇形展开的一圈红橙色羽毛**，像印第安战冠；**羽根是白色、羽尖是鲜艳的橙红**，大约 8～12 根，最高的一根在正中。
- **垂绳与系带**：从头部两侧和颈部垂下**红色与蓝色（另一条偏白）的绳结与系带**，尾端打着结、有穗子。
- **躯干**：**灰色金属／骨质的分节躯体**，肩背与后躯覆盖**大块的深灰近黑的装甲板**，板与板之间有缝隙，带铆钉与磨损感。整体像一具用金属与骨头拼起来的战兽。
- **前肢**：灰色金属的粗壮前肢，前端是**三到四根利爪**，爪尖颜色更深；后肢稍短、蹬地蓄力。
- **一点点沙**：只在爪底与躯体边缘留少量飞散的细沙，暗示它是沙之替身——**沙不是主体材质**。
Style/medium: 漫画赛璐璐彩绘，粗细变化的墨线（深紫黑）、简练的大块明暗、少量网点，高对比。配色：**灰银、深灰近黑的主体 + 红橙羽毛 + 红／蓝垂绳**；右上方硬光、左下阴影，金色轮廓高光。
Composition/framing: 完整全身，正面略微三分之四角度，低伏前倾、蓄势待发；最高占画面 84% 高度、最宽占 66% 宽度，四周保留明显的纯背景安全距离。
Scene/backdrop: 背景是**绝对均匀的纯蓝色 RGB(0,0,255)**，无渐变、无纹理、无地板、无投影，方便透明抠图。身体内部不要出现纯蓝色。
Constraints: 只画愚者这一个形体；**不要文字、不要字母、不要数字、不要 Logo、不要卡片边框、不要圆形数值图表、不要棋盘格、不要底座、不要 UI**；不要狗、不要人类、不要第二个角色。
Avoid: 沙土色／米黄／暗金色主调、紫色主调、发光红眼、没有羽毛头饰的光头造型、狮鹫／龙式幻想怪兽、肌肉夸张的人形躯干。
