Use case: stylized-concept
Asset type: 战棋游戏的**战斗场地背景图**（横版 3:2，铺在棋盘底下、上面叠六边形棋盘与棋子）。
Primary request: 画一艘**巨型货轮最外层的甲板**——剧情第五章「力量」的**第一层战场**。整艘船就是一个替身，所以这一层要透出"钢铁做的、但像活着的东西"。**整体必须压暗、低对比**——它是背景，不能抢棋子的可读性。
Subject:
- **甲板（画面主体）**：深灰近黑的**厚重钢板铺面**，能看出**铆钉排列、防滑的菱形纹、焊接缝**；钢板上散布几处**积水的反光**（暗色，不反光到刺眼）与**锈迹斑斑的色块**。
- **甲板上的设备（只要剪影与暗块，不要细节）**：一个**舱口盖**（方形，带铰链与转轮）、**系缆桩**与**盘绕的粗缆绳**、一台**绞盘**、画面边角一点**起重吊臂**的暗色轮廓。**不要画人、不要画货箱堆**。
- **边缘**：甲板的外沿有一圈**舷墙／栏杆**的暗色剪影；栏外是**近乎全黑的海水**（**极暗**，只留一两道极淡的浪纹反光，**不要明亮的天空、不要地平线、不要月亮**）。
- **"它会呼吸"的暗示（关键，但必须克制）**：沿着钢板走向铺着几条**粗大的管线**，管身有**接缝与铆箍**，看上去像**血管一样爬在甲板上**；其中一两处接缝里透出**极淡的暗红／暖橙色微光**，像里面有什么在缓慢搏动。**不要画成怪物、不要画眼睛、不要画嘴**。
Style/medium: 漫画赛璐璐彩绘，深紫近黑的墨线、简练的大块明暗、少量网点。**配色非常克制**：主体是**冷钢灰、深蓝紫、近黑**，只在锈迹上有一点暗褐红、接缝微光处有一点暗橙。
Lighting/mood: 低照度、低对比、无强高光；光源是**阴天的冷漫射光**（来自画面斜上方），甲板缝隙里那点暖光作为唯一一点暖色；整体阴沉、封闭、"这地方不对劲"的压迫感。
Composition/framing: 横版 3:2，**高角度俯视、略微倾斜**，甲板占满整个画面（没有天空、没有海平线的纵深）；甲板上的设备分散在四周、**画面正中央留相对空的钢板**（上面要叠棋盘与棋子）；画面四周（尤其四角）**保持更暗**。
Constraints: 只画船上甲板这一层；**绝对不要人物、不要替身、不要怪物、不要僵尸、不要货箱堆**；不要文字、不要字母、不要数字、不要 Logo、不要边框、不要 UI 元素；不要明亮的天空、不要阳光、不要彩色霓虹。
Avoid: 高饱和度配色、明亮的蓝天、写实的照片质感、漫画分格、明显的血盆大口或眼睛等"怪物化"设计、任何高对比的主体物（会盖过棋子）。
