Use case: stylized-concept
Asset type: 战棋游戏的**地形素材**（一张 2×2 网格图，之后按格切成 4 个透明小图标，用在棋盘格子上）。这四个是"客机机舱"版本的替换皮肤，**效果与原来的岩石/草丛/恢复点/毒沼一一对应，只是长得符合飞机**。
Primary request: 在一张**2×2 网格**里画**四个互不相干的物件**，每个物件各自居中占满自己那一格，四者之间留出明显空隙、**绝对不要互相接触或重叠**。
四格的内容（顺序：左上 → 右上 → 左下 → 右下）：
1. **左上（对应"岩石"＝挡路的障碍）**：**堆叠的行李箱**——一个深色的硬壳登机箱横倒着，上面压着一个鼓鼓的帆布旅行包，箱角有金属包边与磨损，整体像"堵住过道的一堆行李"。
2. **右上（对应"草丛"＝提供掩护）**：**一堆椅背靠枕与毛毯**——浅色织物堆叠在一起，有几条毛毯垂下来，边角露出座椅头枕的轮廓，像乘客慌忙离开后留下的掩护物。
3. **左下（对应"恢复点"＝补给）**：**一架机舱送餐车**——矮小的金属推车，带四个小轮与扶手，台面上放着两三个饮料杯与一个小水壶，金属表面有冷色反光。
4. **右下（对应"毒沼"＝踩上去受伤）**：**一滩泄漏的燃油**——地面上摊开的深色油渍，边缘不规则、有**虹彩般的青紫反光**与几点溅开的小油珠，旁边是一小段破损的地板边缘（暗示危险、不要踩）。
Style/medium: 漫画赛璐璐彩绘（与游戏其它地形素材同一风格）：粗细变化的**深紫黑墨线**、简练的大块明暗、少量网点，高对比；每个物件都当成"贴在地上的小道具"来画。
Composition/framing: 严格的 **2×2 等分网格**；每个物件在自己的格子里**居中、不越界**，四周留出至少 12% 的空白；四个物件的**视觉体积尽量接近**（切成图标后大小才会一致）。
Scene/backdrop: 背景是**绝对均匀的纯洋红色 RGB(255,0,255)**（方便程序抠图）；物件内部**不要出现洋红色**。
Lighting/mood: 四个物件统一右上方硬光，左下深紫阴影，金色轮廓高光。
Constraints: 只画这四个物件；不要网格线、不要边框、不要文字、不要字母、不要数字、不要 Logo、不要人物、不要机舱背景、不要让四个物件连成一体。
Avoid: 写实照片质感、明亮的蓝天白云、把行李箱画成纸箱、把油渍画成水洼（要深色油光）、高饱和的彩色背景。
