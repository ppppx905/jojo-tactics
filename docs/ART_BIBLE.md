# 星尘战棋 · 美术与交互规范

方向为 JOJO 第三部的漫画战术界面：深靛紫舞台、骨白正文、沙金行动强调，蓝色 P1 与品红 P2。人物保留承太郎、DIO、花京院、阿布德尔和各自替身的身份特征。右上主光，左下投影，硬边赛璐璐与少量网点。

## 画面层级

1. 中央六角棋盘为战术焦点。左右角色舱相同宽度，不能因选中或长说明改变棋盘位置。
2. 大肖像提供角色识别；棋盘使用全身立姿。阵营由底座颜色、圆／菱形和 P1/P2 文字同时识别，角色与替身由“主／替”标签区分。
3. 底部行动台固定为当前行动者、动作、AP 与结束回合。目标反馈独立于规则提示，错误不能被 hover 覆盖。
4. 角色、技能、地形使用位图；边框、文字、图标、指示范围、速度线和数值反馈用程序绘制。

## 视觉实现

| 项目 | 规范 |
|---|---|
| 背景／面板 | `--ink` / `--surface`，明确亮度差，克制网点 |
| 正文／说明 | `--text` / `--muted`；主标题与数字用得意黑 |
| 主要行动 | `--gold`；选中框、AP、结束回合使用同一金色 |
| 阵营 | P1 蓝 / P2 品红；高对比模式 P1 蓝 / P2 橙 |
| 移动／攻击 | 三角+范围边界 / 斜线+目标环；不只靠颜色 |
| 禁用 | 保留可读文字、CD/AP，淡化图标与斜线；可聚焦查看原因 |
| 演出 | 只在动作确实结算后触发；减少动画时保留规则文字与数值 |
| 地形 | 使用固定逻辑尺寸 33–42px，裁切在单格安全六边形内 |
| 棋子 | 统一竖向透明画布 192×288；显示高度 50/52 逻辑像素；格内裁切 |
| 坐标 | `src/core/hex.js` 是唯一来源；不复制偏移公式到输入脚本 |
| 性能 | 静态地形离屏缓存；图片描边预合成；backing scale ≤2 |

## 素材目录

- `assets/out/portraits/`：现有四人肖像裁切为 WebP，用于选人与角色舱。
- `assets/out/standees/`：八个可独立替换的使者／替身透明立姿。
- `assets/out/cutins/`：四组角色／替身大招插画。字幕、时长和动效由程序控制。
- `assets/out/terrain/`：沿用原地形造型，按格内安全范围缩放。
- `design/prompts/`：本轮实际生图及背景修正提示词。

重新处理本轮素材：`python3 tools/prepare_art.py`（需要 Pillow）。原始切图管线 `tools/slice.py` 保留用于地形等原素材。

素材图只包含身份、造型和基础光影；不要烘焙队伍颜色、HP、数字、冷却、边框或按钮。新图用独立版本名落盘，确认主体、裁切和透明边缘后再接入。素材记录见 `design/ASSET_REPORT.md`。
