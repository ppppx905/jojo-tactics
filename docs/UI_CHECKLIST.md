# UI 修复与验收

本轮范围：本地双人 / AI 对战的表现层与交互修复。联网服务和部署不属于本轮 UI 交付。

实施顺序：统一几何与输入 → 独立规则状态/修复交互 → 对称桌面布局与响应式 → 接入立绘/棋子/技能演出 → 浏览器流程与逐格验收。角色、技能和基础数值沿用原版；修正不合理的状态边界，不建设旧新引擎逐帧回放体系。

- [x] P0 统一棋盘格心、缩放与鼠标命中，逐格验证。`hex.js` 统一几何；六组视口 / DPR 共 924 次真实格心点击与悬停通过，六角边界另有核心测试。
- [x] P0 对称布局、无横向溢出、选中不改变棋盘位置。桌面角色舱等宽，棋盘中心误差 < 0.01 CSS px；窄屏仅棋盘内部滚动，页面无溢出。
- [x] P0 双侧 HP / AP 同步，清除选人残留，恢复规则警告。浏览器验证伤害同步、双人轮转、重开清空与 hover 不覆盖拒绝原因；核心测试覆盖 0 AP 和强化 4 AP。
- [x] P0 重开 / 投降确认、结算 / 重开流程。真实 UI 验证取消及确认、死亡与认输的不同原因、再战和重新选人；AI 暂停与旧局计时器隔离通过。
- [x] P1 人物肖像与八个棋子身份资源接入，主 / 替、P1 / P2 双重标识。四张肖像、八张透明立姿及四组大招图接入；已查看棋盘截图与素材 contact sheet，见[素材记录](design/ASSET_REPORT.md)。
- [x] P1 技能图标、消耗、冷却、禁用原因与说明。固定按钮结构，悬停 / 焦点 / 点击可查看说明；浏览器验证 CD、AP、施法者限制及技能真正结算后的插画。
- [x] P1 同伴连线、落点距离、地形说明、普攻与技能伤害预览。预览复用结算公式；核心测试覆盖防御、柱子击碎（不再反噬扣血）、吸血与减疗，浏览器核对预览和实际 HP。
- [x] P1 取消选择 / 技能瞄准，已结算动作不提供伪撤销。Esc 与取消按钮可退出瞄准；火焰首格扣费、0 AP 续铺、完成后保留已落地火焰均通过回归。
- [x] P2 场景素材单格化、网格清晰、伤害 / 治疗 / 技能反馈与音效。地形和棋子限制在格内；事件绑定数字、移动、受击、演出与程序音效；移动首帧时间边界已有回归。
- [x] P2 选人界面、帮助、色弱模式、减少动画、键盘焦点。高对比、减少动画和静音可保存；键盘行动、弹窗焦点约束与窄屏单位按钮焦点恢复通过。
- [x] P2 离线与启动失败提示。已加载本地对局可离线继续；独立浏览器上下文模拟模块加载失败，15 秒后显示重试，恢复资源后重试成功。
- [x] 验收 1920×1080 / 1366×768 / 窄屏截图、真实点击、主流程回归。2026-09-11 执行 `npm run check`：19 项核心测试、19 组浏览器检查全部通过，完整报告 `scope=complete`、`errors=[]`。
